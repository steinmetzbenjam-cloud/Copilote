# Copilote

Application macOS (SwiftUI + SwiftData) pour préparer un voyage en groupe et partager les informations (itinéraire, réservations, lieux) avec tous les membres. Inspirée de Wanderlog.

Ouvrir `Copilote.xcodeproj` dans Xcode et lancer (⌘R).

## Partage avec le groupe

La synchronisation et le partage passent par iCloud (CloudKit). Voir [SETUP-ICLOUD.md](SETUP-ICLOUD.md).
